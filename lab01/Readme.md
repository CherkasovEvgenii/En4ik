## Ручной расчёт для варианта 5 (до запуска программы)
**Вводные данные:**
Заказ: спорт инвентарь в школу. Заказчик: Пётр Иванов. 
Позиция 1 (мячи): 7 шт. по 550.50 руб.
Позиция 2 (скакалки): 8 шт. по 300.00 руб.
Доставка: 400.00 руб. Внесено: 7000.00 руб.

**Расчёты:**
* Стоимость мячей: 7 * 550.50 = 3853.50 руб.
* Стоимость скакалок: 9 * 300.00 = 2700.00 руб.
* Товары без доставки: 3853.50 + 2700.00 = 6553.50 руб.
* Общая сумма с доставкой: 6553.50 + 400.00 = 6953.50 руб.
* Общее количество: 7 + 9 = 16 шт.
* Сдача: 7000.00 - 6953.50 = 46.50 руб.

## Ответы на контрольные вопросы

1. **Различие строки и числа:** Строка (`str`) — это текст для хранения слов и символов, математика с ними не работает напрямую. Числа (`int`, `float`) используются для расчетов.
2. **Порядок вычислений:** Сначала скобки, потом умножение и деление, затем сложение и вычитание.
3. **Назначение временной переменной:** Чтобы при обмене значениями двух переменных (`a` и `b`) не потерять значение первой переменной при её перезаписи.
4. **Форматирование денежного вывода:** Для денег всегда показывают две цифры после точки (копейки). В Python это делается через `:.2f` внутри f-строки (например, `{cost:.2f}`).
