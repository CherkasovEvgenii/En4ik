# Лабораторная работа 5. Обработка строк

Вариант: **5** (слова заканчиваются на а).

## Файлы

- `normalize.py` — нормализация текста
- `palindrome.py` — проверка на палиндром
- `replace.py` — замена `:` на `-` с подсчётом
- `variant.py` — индивидуальный вариант 5

Запуск: `python normalize.py` (и так же остальные).

## Как работают программы

1. **normalize.py** — `split()` разбивает строку на слова и сам убирает лишние пробелы, потом `" ".join(...)` собирает слова обратно через один пробел. Длину считаю до и после.
2. **palindrome.py** — перевожу текст в нижний регистр, убираю пробелы через `replace(" ", "")`. Если строка пустая — `Нет текста`, если равна себе в обратном порядке (`[::-1]`) — `Палиндром`.
3. **replace.py** — сначала `count(":")`, потом `replace(":", "-")`.
4. **variant.py** — разбиваю строку на слова, в цикле очищаю каждое слово через `strip(".,!?;:")` и `lower()`, пустые пропускаю, остальные проверяю условием `len(clean_word) == 4`.

## Проверки

### normalize.py

| Ввод | Результат |
|---|---|
| `  Один   два  ` | `Один два`, слов 2, длина 14 → 8 |
| пустая строка | длина 0 → 0, слов 0 |

### palindrome.py

| Ввод | Результат |
|---|---|
| `А роза упала на лапу Азора` | Палиндром |
| `а    ` | Палиндром |
| строка из пробелов | Нет текста |
| `Python` | Не палиндром |
| `А!` | Не палиндром |

### replace.py

| Ввод | Результат |
|---|---|
| `a::b:` | `a--b-`, замен 3 |
| `abc` | `abc`, замен 0 |

### variant.py (вариант 5)

| Ввод | Результат |
|---|---|
| `Анна, армия! Я читаю. Книга, край, рама.` | анна, Книга, рама; количество 3 |
| `Анна, книга! рама.` | анна; количество 1 |
| пустой ввод | Нет совпадений, количество 0 |
| `!!!` | Нет совпадений, количество 0 |

Все результаты совпали с ожидаемыми.

## Ответы на вопросы для защиты

**Неизменяемость строк.** Строку нельзя поменять "на месте". Методы вроде `lower()` или `replace()` не меняют исходную строку, а возвращают новую. Поэтому результат нужно сохранять в переменную или сразу выводить.

**Слово и подстрока.** Подстрока — любой кусок строки подряд, например `"ра"` есть и в `"рама"`, и в `"храбрый"`. Слово — часть, которая получилась после `split()`, то есть отделённая пробелами.

**Почему правила для пунктуации нужно задать заранее.** От них зависит результат: например, `"А!"` не палиндром, потому что `!` считается символом. А в варианте слово `"край,"` с запятой имеет длину 5, а без запятой — 4. Если правила не задать, программа может дать другой ответ.
