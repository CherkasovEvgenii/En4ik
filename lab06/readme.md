# Лабораторная работа №6. Списки и обработка наборов данных
**Вариант 5: Положительные числа**

В работе представлены 4 программы. Для каждой приведены тестовые проверки. 

### 1. Статистика (statistics.py)
Программа вычисляет базовую статистику введенных чисел. Если ввод пустой, выводит сообщение.

| Ввод | Результат |
|---|---|
| `-2 0 5 3` | Количество: 4, Сумма: 6, Минимум: -2, Максимум: 5, Среднее: 1.50 |
| `8` | Количество: 1, Сумма: 8, Минимум: 8, Максимум: 8, Среднее: 8.00 |
| *(пустой ввод)* | Нет данных |

### 2. Независимое преобразование (transform.py)
Заменяет отрицательные числа их модулями. Исходный список сохраняется.

| Ввод | Результат |
|---|---|
| `-2 0 5 -2` | Исходный: `[-2, 0, 5, -2]`, Новый: `[2, 0, 5, 2]` |

### 3. Позиции максимума (positions.py)
Находит все индексы максимального элемента.

| Ввод | Результат |
|---|---|
| `7 7` | `[0, 1]` |
| `-3 -1 -2` | `[1]` |
| *(пустой ввод)* | Нет данных |

### 4. Индивидуальный вариант 5 (variant.py)
Условие: отобрать **положительные числа**. Вывести их в исходном порядке, количество, сумму и отсортированную копию.

| Ввод | Результат |
|---|---|
| `-8 -3 0 6 6 1` | Результат: `[6, 6, 1]`, Количество: 3, Сумма: 13, Сортированная копия: `[1, 6, 6]` |
| `-5 -2` | Результат: `[]`, Количество: 0, Сумма: 0, Сортированная копия: `[]` |
| *(пустой ввод)* | Результат: `[]`, Количество: 0, Сумма: 0, Сортированная копия: `[]` |
