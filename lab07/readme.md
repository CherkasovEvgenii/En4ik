# Лабораторная работа №7. Функции и автоматические проверки
**Вариант 5: Не больше порога**

В работе реализованы функции для вычислений и их проверка с помощью `assert`.

## Запуск программ

1. Запуск основной демонстрации:
   `python main.py`
2. Запуск автоматических тестов:
   `python test_functions.py`

## Описание индивидуального варианта (variant 5)
Функция `select_numbers(numbers, threshold)` возвращает новый список, содержащий числа, которые **не больше порога** (то есть `<= threshold`). Порядок элементов и повторы сохраняются. Исходный список не изменяется.

## Результаты тестирования (test_functions.py)
Все базовые и дополнительные проверки (включая граничные значения и проверку на неизменность исходного списка) успешно пройдены.
