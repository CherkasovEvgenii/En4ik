# Лабораторная работа №8. Словари, множества и кортежи
**Вариант 5: Видеокурсы (поле amount — Количество уроков)**

В работе представлены 4 программы. Для каждой приведены тестовые проверки.

### 1. Частоты слов (word_counts.py)
Программа приводит текст к нижнему регистру, удаляет знаки препинания по краям слов и считает количество вхождений, выводя результат по алфавиту.

| Ввод | Результат |
|---|---|
| `Python, python! SQL? .` | `python: 2`<br>`sql: 1` |
| `!!!` | `{}` |

### 2. Учебные интересы (topics.py)
Программа использует множества для поиска общих тем (пересечение) и всех уникальных тем (объединение), выводя их в отсортированном виде.

| Ввод (Список 1) | Ввод (Список 2) | Результат |
|---|---|---|
| `python sql python` | `sql git` | Общие темы: `['sql']`<br>Все темы: `['git', 'python', 'sql']` |
| `python` | `git` | Общие темы: `[]`<br>Все темы: `['git', 'python']` |

### 3. Запись и пара (records.py)
Демонстрация работы со словарем (создание, изменение, добавление ключей) и кортежем (распаковка).

| Действие | Результат |
|---|---|
| Создание словаря и добавление ключей | `{"title": "Python для начинающих", "hours": 15, "completed": False}` |
| Создание кортежа `(title, hours)` и распаковка | `Title: Python для начинающих, Hours: 15` |

*Пояснение:* Запись удобно представлять словарем, так как он позволяет обращаться к данным по именам ключей (в отличие от индексов списка) и легко расширяется новыми полями.

### 4. Индивидуальный вариант 5 (variant.py)
**Условие:** Предметная область — Видеокурсы. Поле `amount` — количество уроков.

Программа считает сумму уроков по категориям и ищет названия курсов по введенной категории.

| Ввод (Категория) | Результат: Сводка по категориям | Результат: Поиск названий |
|---|---|---|
| `Базы данных` | Базы данных: 22<br>Дизайн: 8<br>Программирование: 35 | `['SQL для начинающих', 'SQL Advanced']` |
| `Программирование` | Базы данных: 22<br>Дизайн: 8<br>Программирование: 35 | `['Python Basics', 'Data Science']` |
| `Нет такой` | Базы данных: 22<br>Дизайн: 8<br>Программирование: 35 | `[]` |
