# Лабораторная работа №10. Текстовые файлы и обработка ошибок

**Вариант 5: Элементы, кратные 3**

В работе реализован модуль для чтения текстовых файлов с проверкой ошибок, обработка матриц и запись отчета.

### 1. Чтение таблицы (files_lab.py)
Функция `read_matrix(path)` читает матрицу из файла. Проверяет заголовок, количество строк и столбцов, а также то, что данные являются целыми числами. В случае ошибки выбрасывает `ValueError` с указанием номера строки.

### 2. Индивидуальный вариант 5 (variant.py)
Вычисление оформлено отдельной функцией `selected_sum(matrix)`. Она находит сумму элементов матрицы, кратных 3. Если таких элементов нет, возвращает `0`.

| Ввод (матрица) | Результат |
|---|---|
| `[[1, -2, 3], [4, 0, -6]]` | `-3` (сумма 3, 0 и -6) |
| `[[1, 2], [4, 5]]` | `0` (нет кратных 3) |

### 3. Основная программа (main.py)
Запрашивает у пользователя положительное целое число (с обработкой ошибок ввода). Затем читает `matrix.txt`, вычисляет суммы строк и столбцов, а также вызывает `selected_sum` из `variant.py`. Записывает результат в `report.txt`.

| Файл (matrix.txt) | Результат (report.txt) |
|---|---|
| `2 3`<br>`1 -2 3`<br>`4 0 -6` | Суммы строк: 2 -2<br>Суммы столбцов: 5 -2 -3<br>Результат варианта: -3 |

### 4. Проверки (test_files.py)
Файл `test_files.py` использует `tempfile.TemporaryDirectory()` для создания временных файлов. Проверены следующие сценарии:

| Содержимое или ситуация | Ожидаемое поведение |
|---|---|
| `1 1` и строка `0` | Матрица `[[0]]` |
| Пустой файл | `ValueError` |
| Заголовок `0 3` | `ValueError` |
| Заголовок `1 2`, строка `1` | `ValueError` с указанием строки 2 |
| Заголовок `1 2`, строка `1 x` | `ValueError` с указанием строки 2 |
| Заголовок `1 1`, две строки данных | `ValueError` |
| Отсутствующий путь | `FileNotFoundError` в функции, сообщение в основной программе |
| Матрица `[[1, -2, 3], [4, 0, -6]]` | `selected_sum` возвращает `-3` |
