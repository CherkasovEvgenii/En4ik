## Описание проекта
Консольная программа для управления списком видеокурсов. Позволяет добавлять курсы, отмечать их как пройденные, искать по названию и собирать статистику по категориям.

## Структура проекта
* `main.py` — интерфейс (консольное меню) и цикл программы.
* `logic.py` — бизнес-логика (добавление, поиск, статистика).
* `storage.py` — работа с файлами JSON (чтение и запись).
* `test_logic.py` — автотесты для бизнес-логики.
* `test_storage.py` — автотесты для сохранения/загрузки.
* `data.json` — файл с данными.
